# GambaCode

> Software, experiments and ideas.

GambaCode is an independent space for building things, experimenting with technology, and sharing projects worth documenting.

## What you'll find here

- 🧩 **Projects** — Applications, tools and things built from scratch.
- 🧪 **Experiments** — Ideas turned into code, just to see where they lead.
- 📝 **Writing** — Technical notes, discoveries and things learned along the way.
- 🔧 **Open source** — Selected projects, utilities and experiments.

## Philosophy

> Code before names.  
> Projects before labels.

Some things are built to solve a problem.  
Others are built simply because they seemed interesting.

Both are worth building.
